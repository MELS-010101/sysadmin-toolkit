# SysAdmin Toolkit 🛠️

Набор простых Bash-скриптов для ежедневных задач системного администратора.

## Инструменты

### backup.sh
Архивирует указанную папку в `.tar.gz` с датой и временем. Ведёт лог действий.

**Использование:**

    ./bin/backup.sh <папка>

### inventory.sh
Подсчитывает количество файлов в указанной директории.

**Использование:**

    ./bin/inventory.sh <папка>

### cleanup.sh
Удаляет `.log` файлы старше 7 дней из папки `logs`.

**Использование:**

    ./bin/cleanup.sh

### bigfiles.sh
Находит файлы размером больше 10 МБ в текущей директории.

**Использование:**

    ./bin/bigfiles.sh

### disk_monitor.sh
Проверяет заполненность диска и предупреждает, если занято больше 80%. Ведёт лог.

**Использование:**

    ./bin/disk_monitor.sh

### dupfinder.sh
Находит файлы с одинаковыми именами в разных папках. Служебную папку .git игнорирует.

**Использование:**

    ./bin/dupfinder.sh <папка>

### portcheck.sh
Стучит в указанный порт и отвечает, открыт он или закрыт. Работает через встроенную возможность Bash (/dev/tcp), внешних утилит не требует.

**Использование:**

    ./bin/portcheck.sh <хост> <порт>

Пример: ./bin/portcheck.sh github.com 443

### logrotate.sh
Ротация логов: пакует логи старше 7 дней в архив tar.gz, проверяет архив и только потом удаляет оригиналы. Архивы старше 30 дней подчищает автоматически.

**Использование:**

    ./bin/logrotate.sh <папка_логов> <папка_архивов>

Пример: ./bin/logrotate.sh logs logs/archive


### toolkit.sh
Меню-диспетчер: одна дверь входа во все инструменты. Показывает меню по кругу, пока не выберешь 0.

Пункты меню:
1. Инвентаризация файлов (inventory.sh)
2. Поиск дубликатов имён (dupfinder.sh)
3. Проверка диска (disk_monitor.sh)
4. Проверка порта (portcheck.sh)
5. Ротация логов (logrotate.sh)
0. Выход

**Использование:**

    ./toolkit.sh

    ./toolkit.sh

## Тестовые данные

Папка test/ содержит фикстуру для dupfinder: два файла report.txt в разных подпапках.
Запусти ./bin/dupfinder.sh test — должен найти дубликат.

## Установка

    git clone https://github.com/твой_логин/sysadmin-toolkit.git
    cd sysadmin-toolkit
    chmod +x bin/*.sh

## Требования

- Linux / macOS
- Bash 4+
- Стандартные утилиты: tar, find, wc, tee
