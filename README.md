# SysAdmin Toolkit 🛠️

Набор простых Bash-скриптов для ежедневных задач системного администратора.

## Инструменты

### backup.sh
Архивирует указанную папку в `.tar.gz` с датой и временем. Ведёт лог действий.

**Использование:**

    ./bin/backup.sh <папка>

### inventory.sh
Подсчитывает количество файлов в указанной директории.

**Использование:**

    ./bin/inventory.sh <папка>

### cleanup.sh
Удаляет `.log` файлы старше 7 дней из папки `logs`.

**Использование:**

    ./bin/cleanup.sh

### bigfiles.sh
Находит файлы размером больше 10 МБ в текущей директории.

**Использование:**

    ./bin/bigfiles.sh

### disk_monitor.sh
Проверяет заполненность диска и предупреждает, если занято больше 80%. Ведёт лог.

**Использование:**

    ./bin/disk_monitor.sh

### dupfinder.sh
Находит файлы с одинаковыми именами в разных папках. Служебную папку .git игнорирует.

**Использование:**

    ./bin/dupfinder.sh <папка>

### toolkit.sh
Меню-диспетчер: запускает любой инструмент по цифре и показывает меню снова, пока не выберешь 0.

**Использование:**

    ./toolkit.sh

## Тестовые данные

Папка test/ содержит фикстуру для dupfinder: два файла report.txt в разных подпапках.
Запусти ./bin/dupfinder.sh test — должен найти дубликат.

## Установка

    git clone https://github.com/твой_логин/sysadmin-toolkit.git
    cd sysadmin-toolkit
    chmod +x bin/*.sh

## Требования

- Linux / macOS
- Bash 4+
- Стандартные утилиты: tar, find, wc, tee
